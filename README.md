### 📊 Pesquisa de Satisfação | Support Analytics

Aplicação web para coleta e análise da experiência do cliente, utilizando indicadores CSAT, CES e NPS.

**Tecnologias:** React, JavaScript, Supabase, PostgreSQL e ApexCharts.

- Pesquisa de satisfação responsiva
- Autenticação administrativa
- Dashboard com indicadores e gráficos
- Filtros por período
